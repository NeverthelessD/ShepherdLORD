영복교회 성도 돌봄 · 맥 앱

ShepherdLORD 사용 · 주의 가이드  |  새가족 · 환우 · 임신 명단을 함께 보고 고쳐요

1

압축 풀기

받은 zip 파일을 두 번 클릭하면 ShepherdLORD 폴더가 생겨요. 안의 ShepherdLORD 앱을 응용 프로그램 폴더로 끌어다 놓아요.

📁 ShepherdLORD
   🐑 ShepherdLORD → 응용 프로그램
2

처음 열기

앱을 열면 "확인할 수 없습니다" 창이 떠요. 완료를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 그래도 열기를 눌러요. 처음 한 번만 해요.

🔒 개인정보 보호 및 보안
"ShepherdLORD"이(가) 차단되었습니다.
그래도 열기
3

접속 코드 입력

관리자에게 받은 접속 코드를 치고 Enter. 한 번만 입력하면 다음부터는 바로 열려요.

성도 돌봄
다음부터는 묻지 않아요
4

Dock에 두기

Dock의 어린양 아이콘을 오른쪽 클릭 → 옵션 → Dock에 유지. 창을 닫아도 Dock에 남아 있고, 아이콘을 누르면 다시 열려요.

🐑 오른쪽 클릭
옵션 → ✓ Dock에 유지

⚠️ 꼭 알아 두세요

  • 끝낼 때는 ⌘Q. 창만 닫으면 Dock에 남아 있어요.
  • 접속 코드는 관리자에게 따로 받고, 다른 사람에게 알려 주지 마세요.
  • 여럿이 쓰는 컴퓨터라면 다 쓴 뒤 홈 화면 아래 "이 기기에서 나가기"를 눌러요. 접속 코드가 바뀌면 다시 입력해요.
  • 새 기능은 앱을 열 때 자동으로 반영돼요. 앱 자체의 새 버전은 앱이 알려 줘요.
  • 인터넷이 끊기면 안내가 나와요. 연결한 뒤 다시 시도를 눌러요.
  • 문제가 생기면 메뉴 막대 ShepherdLORD → 진단 정보 보기 파일을 관리자에게 보내 주세요.
  • 예전 macOS 라면 앱을 Control-클릭 → 열기로 처음 열 수 있어요.
  • 사파리 · 크롬의 구글 계정과 상관없이 잘 열려요.
