받은 zip 의 압축을 풀고 앱을 열면 돼요. 자세한 방법은 zip 안의 사용 가이드 이미지를 봐 주세요.

### 폴더

| 폴더 | 내용 |
|---|---|
| `webapp/` | 구글 시트에 붙는 웹앱 원본 (Code.gs, Index.html), 일괄입력 양식, 바로가기 html |
| `app/` | 맥 앱 (Swift · AppKit · WKWebView) 과 사용 가이드 |
| `windows/` | 윈도우 앱 (C# · WinForms · WebView2) 과 사용 가이드 |
| `download/` | 내려받기용 최신 zip 한 개 |
| `releases/` | 앱 자동 업데이트용 파일 (최신판만) |
| `scripts/` | 빌드 · 내려받기 정리 스크립트 |
