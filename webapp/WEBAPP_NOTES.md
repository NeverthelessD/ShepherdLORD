# 영복교회 성도 돌봄 앱 — 프로젝트 노트

## 개요
- 새가족과 환우를 관리하는 휴대폰·컴퓨터 겸용 웹앱.
- 구조: 구글 스프레드시트(데이터) + Google Apps Script 웹앱(화면). 비용 0원.
- road-mac-app 원칙을 따르되 맥 전용 부분(Dock 앱, 맥 빌드 서버, 자동 업데이트 zip)은 제외.
- 저작권 표시: 화면 아래, 사용 가이드 이미지에 `made by. Nevertheless_D`.

## 데이터 항목
### 새가족
연번, 이름, 성별, 등록일, 연생, 인도자, 사진(드라이브 저장, 올리면 사진촬영 자동 체크),
새가족교육 1~4강(강별 체크 + 날짜), 등록심방(여부 + 날짜), 전도회, 목장(연결 여부 + 목장 이름),
신급(학습/세례/입교/없음 중 하나), 가족(가족 묶음 ID, 관계, 신앙세대주 여부).
- 전도회: 남자는 1~10남전도회, 여자는 1~15여전도회. 성별에 따라 목록이 바뀜.
- 등록: 개인 또는 가족 단위. 가족 단위면 신앙세대주 1명 지정.
- 목록에는 신앙세대주만 보이고, 누르면 가족이 아래로 펼쳐짐.

### 환우
이름, 성별, 연생, 병명, 병원, 현재 상황(입원/통원 치료/회복 중/요양 + 메모), 다음 진료 예정일(D-day 표시), 사진.

## 권한 (확정)
- 구글 로그인 없음. 웹앱 배포 설정: "실행: 나(교회 공용 계정)", "액세스: 모든 사용자".
- 앱을 열면 첫 화면이 접속 코드 입력. 코드 하나만 입력하면 서버가 어떤 코드인지 보고 권한을 줌.
  다른 코드를 더 입력하면 권한이 더해짐(예: 보기 코드 + 환우 코드).
- 마스터 코드: 모든 화면 보기·입력·수정(새가족 수정 + 환우). 기록에는 "마스터 코드"로 남음.
- 새가족 보기 코드: 새가족 모든 항목 보기(사진 포함, 읽기 전용).
- 새가족 수정 코드: 새가족 보기 + 등록·수정·사진 바꾸기.
- 환우·임신: 마스터 코드로만 보기·수정. (2026-11-05 환우 코드 폐지)
- 코드 없이는 어떤 데이터도 보내지 않음. 누가 접속했는지는 알 수 없으므로 변경기록에는 "어떤 코드로 수정했는지"와 시간을 남김.
- 코드는 스프레드시트 "설정" 시트에 저장, 서버에서 확인. 화면 코드에 넣지 않음.
- 5번 틀리면 10분 잠금. 코드 인증은 그 기기에서 계속 유지(180일, 쓸 때마다 다시 180일로 늘어남).
  로그인 정보에는 코드를 그대로 두지 않고 기기별로 바꾼 값(SHA-256)만 둠. 설정 탭에서 코드를 바꾸면 그 코드로 들어온 기기는 그 권한을 잃음(모든 기기 로그아웃은 코드 바꾸기로).
- 사용 가이드 이미지에 코드 숫자를 적지 않음.
- 초기 코드는 사용자에게 받음(대화 기록 참고). 이 파일에는 적지 않음.

## 파일 구조
- `Code.gs` — 서버. `setup()`이 시트 4개(새가족, 환우, 설정, 변경기록)와 드라이브 사진 폴더를 만들고 기본 코드를 넣음.
  공개 함수: login, logout, getVersion, getData, registerNewcomers, updateNewcomer, deleteNewcomer,
  savePatient, deletePatient, uploadPhoto, getPhoto. 모든 함수가 토큰과 권한을 서버에서 확인.
- `Index.html` — 화면 전체(한 파일). 30초마다 getVersion으로 변경 확인 후 다시 불러옴.
  사진은 기기에서 줄여서(원본 1200px, 썸네일 160px) 올림. 썸네일은 시트에, 원본은 드라이브에.
- 토큰은 스크립트 속성(t_...)에 12시간. 틀린 횟수는 캐시(기기 5번, 전체 30번 → 10분 잠금).
- 시험: 구글 환경을 흉내 낸 가짜 서비스로 브라우저에서 전체 흐름 시험 통과(코드·권한·가족 등록·세대주 변경·사진·환우·잠금).
